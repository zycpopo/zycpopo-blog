## 为什么写博客

学习的过程很容易被遗忘。把零散的理解整理成文章，不只是保存结论，也是在检查自己的思考是否完整。

## 内容如何组织

文章必须属于一个专栏，同时可以带有多个标签。专栏负责形成连续的阅读路径，标签负责连接不同专栏中的相关主题。

```ts
const blog = {
  purpose: "持续学习，认真记录",
  format: "Markdown",
  status: "长期维护"
};
```
